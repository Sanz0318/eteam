# 统一权限管理系统 — 界面设计

> 形式：ASCII 线框图 + Mermaid 导航结构图。
> 面向系统管理员的后台管理界面。

---

## 1. 页面结构（导航）

```mermaid
flowchart LR
    Login["登录页"] --> Home["首页 / 布局"]
    Home --> P1["用户管理"]
    Home --> P2["角色管理"]
    Home --> P3["权限管理"]
    P1 --> P1a["用户列表 / 新增 / 编辑"]
    P1 --> P1b["分配角色弹窗"]
    P2 --> P2a["角色列表 / 新增 / 编辑"]
    P2 --> P2b["分配权限弹窗"]
    P3 --> P3a["权限列表 / 新增 / 编辑"]
```

**分配权限弹窗**：左侧可用权限列表 ⇄ 右侧已分配权限（按资源分组勾选）。

---

## 3. 交互说明
- 角色、权限、管理员等级均为**运行时数据**，界面只负责增删改查与分配，不写死任何固定项。
- 分配角色/权限用**双向穿梭框**（左可用、右已选），体现多对多关系。
- 删除/停用角色后，关联用户即时失去对应权限（生命周期）。
